# 🔥 WASTE TRACE — Leave No Trace. Leave No Waste.

**https://wastetrace.org** — the independent, nonprofit home of the camp-kitchen food loop
for Burning Man camps, Regionals, and burner orgs. Born in a real Black Rock City camp
kitchen (2026). Gifted — never sold.

## What's here
- `index.html` — the whole site. Static, self-contained, zero external requests
  (the site itself leaves no trace: no cookies, trackers, or analytics).
- `tracey-talk.js` — the "Ask Tracey" live chat widget (only talks to a server when
  a visitor opens the chat).
- `agent/` — TRACEY's complete chat-hub source (Cloudflare Worker), deployable by any camp.

## The family & sister repos
- **TERRI 🐢 (camp ops)** — https://github.com/shakaleikaumaka/shellpit — the full
  Terrible Turtles camp playbook + **FORK-THIS-CAMP kit** (agent-kit/) so any camp can
  raise their own Terri. Live at https://theshellpit.com
- **TRACE 👨 (food loop docs & marketplace door)** — https://github.com/shakaleikaumaka/tracewaste —
  live at https://tracewaste.org
